# FlexFund Mobile Application

A modern, AI-powered fundraising platform built with Flutter for Kenyan communities.

## Overview

FlexFund empowers individuals, *chamas*, SACCOs, and churches to easily create and manage fundraising campaigns. Key features include AI-powered description generation (using Gemini), seamless social sharing, real-time progress tracking, and integrated mobile money payments (e.g., M-Pesa).

## Getting Started

This guide will help you set up and run the FlexFund mobile application.

### Prerequisites

* [Flutter SDK](https://flutter.dev/docs/get-started/install) installed and configured.
* A connected mobile device or emulator for testing.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository_url>
    cd flexfund_app
    ```

2.  **Get dependencies:**
    ```bash
    flutter pub get
    ```

### Running the App

1.  **Connect a device or start an emulator.**
2.  **Run the application:**
    ```bash
    flutter run
    ```

## Key Features

* **Effortless Campaign Creation:** Simple steps to set up fundraising events.
* **AI-Powered Descriptions:** Generate compelling campaign text using Gemini integration.
* **Social Sharing:** Easily share campaigns across various platforms.
* **Real-Time Tracking:** Monitor donation progress within the app.
* **Mobile Money Integration:** Seamless contributions via local mobile payment methods.

## Backend

The backend for FlexFund is built using ActionHero with a MongoDB database and is hosted on Heroku. (Backend repository and setup instructions are in a separate document).
